## 📖 About the Game

The game launched globally on **September 16, 2026** for PC (Steam, Epic Games Store), PlayStation 5, and Xbox Series X|S, with the mobile version arriving on **September 23, 2026**.

Set on the vast continent of **Idyll**, you play as a **Pathfinder** — an explorer who can capture and bond with over **200 unique creatures** called Aniimo. The game features a **3-stage evolution system**, environmental variations based on biomes and time of day, and a unique **Twining** mechanic that lets you literally become any Aniimo in your party.

**Key Game Features**:
- 🐉 **200+ Aniimo** to discover, capture, and evolve

- 🎮 **Twining System** — transform into any captured Aniimo

## 🔥 Featured Mods

### 🎥 Uniform Mouse Sensitivity (Camera Fix)

**Source:** Nexus Mods (Bastienreturn) | **Version:** 1.0 | **Updated:** September 22, 2026

A safe, client-side Lua patch that fixes Aniimo's lower vertical mouse sensitivity. The game uses different horizontal (yaw) and vertical (pitch) camera speed values, making vertical movement noticeably slower. This mod makes both axes use the exact same speed value, giving true 1:1 X/Y sensitivity.

**Features**:
- **True 1:1 Sensitivity** — Horizontal and vertical speeds are identical
- **Preserves In-Game Slider** — The sensitivity slider still works
- **No DLL Injection** — Patches an existing Lua script inside game resources
- **No EXE Modification** — `Aniimo.exe` remains untouched
- **Automatic Backups** — Creates verified backups before patching
- **Restore Support** — One-click restore to original files
- **No Background Helper** — No process runs while you play
- **No Networking** — No telemetry or automatic downloads

**Installation**:
1. Install **Python 3.10+** (includes Tkinter for the GUI).
2. Download the mod and extract the ZIP to a normal folder.
3. Save your progress and close Aniimo.
4. Open `Aniimo Camera Axis Fix.py` with Python.
5. Select your game folder, click **Check compatibility**, then **Install fix**.
6. Launch Aniimo normally.

> ⚠️ **Anti-Cheat Note**: The developer states: *"Aniimo's developers have not yet established or publicly communicated a clear policy regarding modding, so there is some uncertainty around the use of mods in general. Although no bans have been reported so far, this mod changes local game resources. Acceptance by Aniimo's anti-cheat is not guaranteed"*.

## ❓ FAQ

### ❓ Is this a cheat or trainer?
**No.** This repository contains **safe client-side Lua patches** and **translation mods**. It does not include memory editors, aimbots, or ESP. The Camera Axis Fix only patches a local camera script — it does not read or write game memory.

### ❓ Will I get banned?
**No, for these client-side mods.** The Camera Axis Fix and Italian Translation modify local files only. However, the Camera Axis Fix developer notes that Aniimo's anti-cheat policy regarding modding is unclear, and acceptance is not guaranteed. Use at your own discretion.

### ❓ Does it work with the latest patch?
**Yes.** The Camera Axis Fix was verified against resource build 3551601. The Italian translation is resilient to updates and re-applies itself after game updates.

### ❓ Does it work on Windows 11?
**Yes.** Fully compatible with Windows 10 and 11 (64-bit).

### ❓ What is the Camera Axis Fix?
It fixes Aniimo's lower vertical mouse sensitivity by patching a Lua camera script. The game uses different yaw/pitch speeds, making vertical movement slower. The mod makes both axes use the same speed value.

### ❓ How to uninstall?
- **Camera Axis Fix**: Open the mod manager, select your game folder, click **Restore original**.
- **Italian Translation**: Run `Disinstalla` from the AniimoITA folder.

### ❓ What if the mod doesn't work?
- Ensure Python 3.10+ is installed (for Camera Axis Fix).
- Check that the game is updated to version 1.1.
- Run the installer as administrator if Windows denies access.
- Verify the mod supports your game version.

### ❓ Does Aniimo have anti-cheat?
**Yes.** The game uses server-side validation for PvP and progression. The developers have not publicly communicated a clear modding policy, so use client-side mods at your own discretion.
